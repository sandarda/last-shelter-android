# Проверка связности помещений — v0.15

В проект добавлена автоматическая проверка связности коридоров при запуске.

## План этажей

- Нижний этаж: гостевая I ↔ арсенал ↔ гостевая II.
- Средний этаж: спальня ↔ гостиная ↔ кухня.
- Верхний этаж: мастерская и лаборатория ↔ склад.

## Вертикальная связь

Центральная винтовая лестница соединяет нижний, средний и верхний этажи. Переход между этажами доступен только рядом с лестничной площадкой; переход выше верхнего и ниже нижнего этажа запрещён.

## Автоматическая проверка

При старте выполняется обход графа коридоров на каждом этаже. Если хотя бы одна комната не достижима из первой комнаты этажа, Godot выведет `push_error` с номером этажа и количеством достижимых помещений. При успешной проверке в Output печатается количество связанных помещений.

Это проверяет логическую связность графа переходов. Физическую проходимость персонажа по финальным тайлам/коллизиям необходимо будет проверить после реализации полноценной изометрической карты.
